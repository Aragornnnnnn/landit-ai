# LAN-217 프리톡 대화 구현 계획

## 목표

실제 외국인과 대화하는 느낌의 프리톡 대화와 지난 기록 조회를 AI·BE에 구현한다.

## 책임 경계

### FE

- 추천 주제 또는 사용자 선시작을 선택한다.
- 사용자 발화 시간만 측정해 BE에 전달한다.
- 누적 발화 시간이 3분에 도달하면 마지막 발화에 시간 제한 도달 여부를 전달한다.
- AI가 감지한 종료 의사에 대해 사용자 확인 UI를 표시한다.

### BE

- 세션, 메시지, 사용자 발화 시간, 종료 상태를 저장한다.
- AI 호출에 필요한 전체 대화 기록을 구성한다.
- 완료된 프리톡만 지난 기록에 노출한다.

### AI

- 추천 주제의 첫 질문을 생성한다.
- 사용자 첫 발화에서 대화 제목을 추론한다.
- 일반 후속 답변, 감정, 속마음, 종료 의사를 한 번에 생성한다.
- `innerThoughtType`을 판단 근거로 계산한다.
- 자연스러운 마무리 메시지를 생성한다.

## 확정 정책

- 상세 피드백은 제공하지 않는다.
- 중단되거나 완료되지 않은 프리톡은 지난 기록에 노출하지 않는다.
- 대화 시간은 사용자의 누적 발화 시간이다.
- 종료 의사는 AI가 boolean으로 판단하고 실제 종료는 FE 확인 후 BE가 처리한다.
- 감정은 LLM이 생성한다.
- 속마음 타입은 `answerCoverage`, `relationshipTone`, `directedAttack`으로 AI 서버가 계산한다.
- 프리톡 맞춤 표현 생성과 학습은 LAN-230에서 구현한다.

### 계약

- AI FastAPI OpenAPI에는 opening, turn, closing 경로만 노출한다.
- BE 공개 API에 bearer 인증과 소유권 검증을 적용한다.
- Remote AI client의 필드명과 enum은 AI OpenAPI와 일치한다.
- 실제 LLM과 외부 네트워크는 자동 테스트에서 호출하지 않는다.
