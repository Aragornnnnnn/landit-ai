# LAN-609 AI 평가 계약 호환성

## 결정과 범위

- 수준 평가 HTTP 기본 계약은 기존 `text-level-v1.3`이다. `X-Landit-Assessment-Version: text-score-v2.0` 요청만 develop에 이미 구현된 100점 평가를 사용한다.
- 기존 c2ebd326의 5단계 루브릭을 별도로 보존하고 같은 생성/재시도/근거 검증 흐름에서 요청별 모델과 스키마를 선택한다. 전역 상태나 추가 모델 호출은 없다.
- 내부 값 접근 이름은 score를 공유하지만 v1의 입력·출력 alias는 level이며 범위는 1~5다. 산술 환산하지 않는다.
- 응답에는 실제 버전을 표시하며, 미관찰 근거 필터도 각 계약의 필드명을 보존한다.
- 총평 highlightMessage는 기존 BE 호환용으로 summaryMessage를 재사용한다. 신규 강조 문구 생성은 BE가 계속 소유한다.
- HTTP 계약은 `docs/api/conversation.md`와 OpenAPI를 기준으로 한다. 배포·롤백과 BE 저장/승급의 전체 계획은 BE `docs/tasks/LAN-609/plan.md`에 둔다.

## 검증

- 기존 v2 HTTP 테스트에 명시적인 버전 헤더를 추가했다. 기본 v1, 명시적 v1/v2, 동일 인스턴스 교차 요청, v1 재시도, 타입·범위·혼합 필드 거부, 비라틴 근거 필터, OpenAPI를 검증한다.
- 전체 `.venv/bin/python -m unittest discover -s tests` 통과: 847건 중 840건 성공, 7건 조건부 제외, 실패·오류 0건. 최종 스키마 메타데이터 변경 후 관련 165건 통과.
- BE의 실제 구형/호환 HTTP 클라이언트와 구형/호환 AI 라우터 5개 조합을 로컬에서 대조해 통과했다. 수준 평가의 LLM 출력과 총평 생성 결과는 fixture이며 직렬화·소비 계약을 검증했다. 자세한 기준 커밋과 조합은 BE 계획 문서에 기록했다.
- 실제 모델 호출·배포·운영 실행은 수행하지 않았다. CI는 별도로 확인한다.
