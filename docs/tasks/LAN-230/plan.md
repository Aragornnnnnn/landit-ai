# LAN-230 프리톡 표현 학습 구현 계획

## 목표

완료된 프리톡의 전체 기록을 바탕으로 맞춤 표현을 준비하고 기존 표현 학습 흐름을 재사용한다.

## 범위

### BE

- 완료된 프리톡의 표현 생성 상태를 관리한다.
- 표현 생성을 비동기로 요청하고 실패한 작업의 재시도와 복구를 처리한다.
- 기존 Writing 표현과 신규 표현의 학습 데이터를 저장한다.
- 지난 프리톡에 표현 생성 상태와 학습 진행 상태를 제공한다.
- 표현 학습 시작, 연습, 완료를 처리한다.

### AI

- 전체 대화 기록과 기존 표현 후보를 바탕으로 맞춤 표현 1~3개를 추천한다.
- 신규 표현의 이미지 없는 텍스트 학습 데이터를 생성한다.

## 확정 정책

- 표현은 세션이 완료된 뒤에만 준비한다.
- 적합한 기존 Writing 표현이 있으면 해당 표현과 학습 콘텐츠를 재사용한다.
- 신규 표현은 이미지를 생성하지 않는다.
- 기존 표현과 신규 표현은 처음부터 모두 해금한다.
- 모든 표현 완료 시 `표현 학습을 완료했습니다` 상태를 제공한다.
- 일부 완료 시 `이어서 학습하기`, 미완료 시 `표현 학습 시작하기` 상태를 제공한다.
- 프리톡에서 완료한 표현은 시나리오 Writing 진행도에 영향을 주지 않는다.
- SQS, 별도 Worker, Redis, Celery를 사용하지 않는다.
- LLM 응답 검증 실패 시 추가 호출 없이 오류를 반환한다.

## 구현 상태

### AI

- [x] 맞춤 표현 추천 생성.
- [x] 신규 표현 학습 콘텐츠 생성.
- [x] 추천 수, 기존 표현 참조, 텍스트 학습 데이터 계약 검증.

### BE

- [x] 비동기 맞춤 표현 생성과 재시도·복구.
- [x] 기존 표현 재사용과 신규 표현 저장.
- [x] 지난 기록의 표현 생성·학습 상태 조회.
- [x] 표현 학습 시작, 연습, 완료.

## 완료 기준

- [x] 완료 후 맞춤 표현 1~3개가 준비된다.
- [x] 기존 표현은 저장된 학습 콘텐츠를 재사용한다.
- [x] 신규 표현은 이미지 없이 텍스트 학습 데이터를 제공한다.
- [x] 표현별 완료 여부와 전체 학습 상태가 제공된다.
- [x] AI와 BE 전체 테스트 및 OpenAPI 계약 검증이 통과한다.
