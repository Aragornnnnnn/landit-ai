# LAN-304 AI 캐릭터 페르소나 설계

## 목표

- BE가 전달한 `characterId`를 프리톡 생성 요청에서 필수로 검증한다.
- opening, turn, closing에 캐릭터별 성격과 영어권 말투를 적용한다.
- inner thought에는 캐릭터 성격만 적용하고 한국어 결과에 영어 방언을 강제하지 않는다.

## 캐릭터 정책

- `chloe`: 친근하고 밝은 미국인 대화 상대. 자연스러운 미국 영어 어휘와 표현을 사용한다.
- `marco`: 여유롭고 유쾌한 호주인 대화 상대. 자연스러운 호주 영어 어휘와 표현을 사용한다.
- `teddy`: 차분하고 다정한 영국인 대화 상대. 자연스러운 영국 영어 어휘와 표현을 사용한다.
- 지역 고유 표현은 자연스럽게 사용하되 학습자가 이해하기 어려운 속어나 과장은 피한다.

## 경계

- 캐릭터 정책은 신뢰 가능한 서버 코드의 고정 매핑으로 관리한다.
- 요청으로 받은 자유 형식 프롬프트를 실행하지 않는다.
- 표현 추천과 학습 콘텐츠 생성은 이번 범위에서 변경하지 않는다.
