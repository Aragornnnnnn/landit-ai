# LAN-602 AI 100점 평가

- 범위와 정책의 단일 기준은 landit-be `docs/tasks/LAN-602/plan.md`다. 사용자 승인: 영역별/종합 100점, 학습 레벨 1~5 및 20점 구간 유지.
- AI 영역 필드는 `level`에서 `score`로 바뀐다. OBSERVED는 1~100 정수와 원문 인용이 필수이고, 미관찰은 둘 다 null이다. 문자열/소수/bool/범위 밖 값과 구버전 level 입력은 거부한다.
- 다섯 영역의 20점 구간별 수행 기준과 구간 안의 불안정/일반/일관된 수행 기준을 정의했다. 5단계 평가 후 환산하지 않으며, 1점 차이의 통계적 정밀도를 주장하지 않는다.
- 최초·통합 총평·재시도 프롬프트, 구조화 스키마, 출력 예산, 안전한 검증 필드 진단을 함께 변경한다.
- 블라인드 평가 도구의 참조 점수, BE 계산 및 manifest 버전을 갱신한다. 과거 manifest/원본 결과를 새 평가에 재사용하지 않는다. 도구의 영역별 withinOne은 이제 1점 이내 일치를 뜻한다.
- BE와 앱은 scoreMax를 기준으로 기존 5점과 신규 100점을 구분해야 한다. 평가 요청을 중지한 상태에서 양쪽을 함께 전환해야 하며 혼합 버전 기간에는 fallback이 발생할 수 있다.
- develop 기준 구현이며 열린 AI #123/#124의 설명 필수화·총평 변경은 병합 시 보존해야 한다.
- 기존 `.venv`의 Python으로 `-m unittest discover -s tests` 전체 통과: 833건, 실패·오류 0건, 제외 7건. `git diff --check` 통과.
- 전 범위 1~100 입력, 0/101/음수/소수/문자열/bool/구버전 level 거부, 미관찰 null, 학습 레벨 경계, 최초/재시도/통합 프롬프트와 API 스키마, 오류 필드 진단을 검증했다.
- 실제 유료 LLM 호출·운영 배포·앱 화면 검증은 수행하지 않았다. 실제 모델의 점수 일관성은 별도 평가가 필요하다.
